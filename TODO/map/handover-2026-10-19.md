## Known issues / open items

1. **`tests/ui/standards.spec.ts:40` fails in Docker** — pre-existing, unrelated to this branch.
   The test fabricates the `/standards/explorer/` document with `route.fulfill`; Chromium's
   Private Network Access policy then blocks every sub-resource from `host.docker.internal`
   ("request client is not a secure context … more-private address space `local`"), so the
   explorer script never loads and all 48 cards stay visible. Fix: add
   `launchOptions: { args: ["--disable-features=BlockInsecurePrivateNetworkRequests"] }` to the
   Chromium project in `_docker/playwright/playwright.config.ts`, or inject the marker template
   with `page.evaluate` instead of fulfilling the document.
2. `npm run data` alone writes nothing (`src/scripts/data.js` never calls `generateData()` when run
   directly); CI's `npm run build` regenerates, so nothing breaks. Pre-existing.
3. `tests/ui/map-page.spec.ts` slow-drag test (~7 s, timing-based) flakes about 1 in 10 runs.
4. Residual a11y polish: `aria-haspopup` stays on "+ Add own requirement" when the selection is
   empty (it shows a notice instead); the "Clear selection" question reaches screen readers only
   via the polite live region; "Details" buttons sit inside `<th>` so their name repeats per cell.
5. Out of scope, from the spec's flow: no `+ Add` buttons on `/search/` results.
6. Large selections (> ~25 qualities) fit the canvas only at ~0.5 zoom; a weak `forceX/forceY`
   would tighten the layout.
7. SVG/PNG export does not embed the webfont (system sans-serif in the image); the selected node's
   highlight is exported as drawn.

## Decisions taken beyond the spec (reverse if you disagree)

- SVG renderer with D3 force (`MapView.js`) instead of the canvas `GraphRenderer`; swap only this file if sigma/FA2 ever lands.
- Priority applies to qualities and own requirements only, not approaches.
- Hidden items: qualities carry `hidden`, other nodes live in `hiddenItems[]`.
- Share-link import offers Replace / Merge / Ignore; JSON file import always replaces.
- Stale quality ids in a stored/shared selection are reported with a "Remove them" button, never pruned silently.
- Markdown export: definitions come from the first blockquote of the quality page; hidden own requirements are exported marked "(hidden on map)".
- Keyboard path to the side panel is the "Details" button in every table row and column header (the SVG is `aria-hidden`).
- Add-from-map search mirrors the header typeahead (lookup JSON, no lunr) rather than the full search page.
